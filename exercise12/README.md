# Exercise 12 - React Hook `useState`

This project completes all seven tasks in the exercise document:

1. A counter that increments on every click.
2. A controlled input with real-time output.
3. A show/hide visibility toggle.
4. A todo list with add and delete actions.
5. A color switcher driven by a dropdown.
6. A case-insensitive search filter.
7. A draggable list that supports reordering.

## Run the project

```powershell
npm install
npm start
```

## Verify the project

```powershell
npm test -- --watchAll=false
npm run build
```
