# Exercise 11 - React Components 2

This project completes all three tasks from the exercise document:

1. A to-do list with add and delete functionality.
2. A calculator supporting addition, subtraction, multiplication and division.
3. A case-insensitive search filter for a technology list.

## Run the project

```powershell
npm install
npm start
```

## Create a production build

```powershell
npm run build
```
